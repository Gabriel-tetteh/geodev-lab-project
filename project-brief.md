# My project brief

## The question
Which communities in the Cape Coast Metropolitan Assembly sit within 200 metres of a watercourse or on low-lying land, putting them at higher flood risk?

## The data I need
- CCMA boundaries — Ghana Statistical Service COD-AB via HDX — Shapefile — https://data.humdata.org/dataset/cod-ab-gha
- Elevation — Copernicus DEM GLO-30 via Copernicus Data Space — GeoTIFF — https://dataspace.copernicus.eu/
- Watercourses/drains — OpenStreetMap Ghana extract via Geofabrik — Shapefile/PBF — https://download.geofabrik.de/africa/ghana.html
- Building footprints — Microsoft Global ML Building Footprints (Ghana) — GeoJSON — https://github.com/microsoft/GlobalMLBuildingFootprints
- Flood-prone community list (for validation) — CCMA Climate Vulnerability Assessment, NAP Global Network — PDF — https://napglobalnetwork.org/wp-content/uploads/2025/07/ghana_2024_cvra_report_cape_coast.pdf
- Population by community — Ghana Statistical Service 2021 Census — PDF/table — https://statsghana.gov.gh/ (not yet confirmed this breaks down to community level — flagged for Step 3)
